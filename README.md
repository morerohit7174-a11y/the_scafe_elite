# ☕ The Cafe Elite — Premium POS Billing App

A complete Flutter POS system with dark gold theme.

## Setup

1. Copy `android/local.properties.template` → `android/local.properties`
2. Update flutter.sdk and sdk.dir paths
3. Run:
```bash
flutter clean
flutter pub get
flutter run
```

## Features
- ✅ POS billing with category filter & search
- ✅ Hold orders (save, edit, resume, delete)
- ✅ Cash / UPI / Card payment
- ✅ SQLite permanent storage
- ✅ PDF bill print & WhatsApp share
- ✅ Product management (add/edit/delete/toggle)
- ✅ Date-wise sales reports
- ✅ Dashboard with real-time stats

## Theme
Dark brown + gold aesthetic (`AppTheme.darkTheme`)
